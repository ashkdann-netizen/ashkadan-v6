# اشکادان | بسته مستقل انتشار V6

این بسته نسخه بازسازی‌شده V6 است. هویت برند، لوگوی رسمی ارسالی کاربر، طراحی مشکی و طلایی و ساختار اصلی سایت حفظ شده‌اند. بخش نمونه‌کارها و گالری عمومی وجود ندارد؛ پیوند اینستاگرام تنها مسیر مشاهده فعالیت‌های تصویری است.

## دارایی‌های تصویری
تمام تصاویر اصلی در `public/assets/` قرار دارند: لوگوی رسمی و تصاویر منتخب ساختمان اشکادان. تصاویر و فونت‌های سایت از میزبان‌های خارجی دریافت نمی‌شوند. پنل مدیریت برای تصاویر از انتخاب‌گر داخلی استفاده می‌کند؛ برای انتخاب تصویر نیازی به آپلود فایل یا لینک خارجی نیست.

## اجرای محلی
```bash
npm install
npm run dev
```

## تنظیمات انتشار رایگان
- پروژه Cloudflare Pages: `ashkadan-v6`
- خروجی: `public` و دستور build خالی
- یک KV namespace در پلن رایگان Cloudflare بسازید و شناسه واقعی آن را در `wrangler.toml` قرار دهید. KV برای ورود مدیر، ذخیره تنظیمات و درخواست‌های مشتریان لازم است.
- R2 برای تصاویر از پیش بسته‌بندی‌شده لازم نیست. قابلیت انتخاب تصاویر آماده بدون R2 کار می‌کند.
- چهار Secret در Pages > Settings > Variables and Secrets تنظیم شوند: `ADMIN_USER`, `ADMIN_PASSWORD` (حداقل ۱۶ نویسه), `SESSION_SECRET` و `ADMIN_PATH_TOKEN` (دو مقدار آخر حداقل ۳۲ نویسه تصادفی).

## انتشار
```bash
npx wrangler pages deploy public --project-name=ashkadan-v6
```

## نکته‌های عملیاتی
- این پروژه به سرویس پولی تصاویر، فونت خارجی، CDN خارجی یا پنل مالی اشتراکی وابسته نیست.
- خود میزبانی وب همچنان روی Cloudflare Pages انجام می‌شود؛ بنابراین برای انتشار عمومی، حساب میزبانی لازم است. استفاده از پلن رایگان تابع محدودیت‌ها و شرایط روز Cloudflare است.
- فرم درخواست و پنل مدیریت برای ذخیره دائمی به KV رایگان نیاز دارند.
- ارسال خودکار پیام واتساپ بدون API رسمی ممکن نیست؛ فرم درخواست در سایت ثبت می‌شود و سپس کاربر می‌تواند پیام آماده واتساپ را ارسال کند.
- بخش نمونه‌کارها/گالری عمداً حذف است.
- دسترسی از شبکه‌های ایران باید پس از انتشار با اینترنت ثابت و همراه چند اپراتور واقعی آزمایش شود. کدنویسی به‌تنهایی امکان تضمین دسترسی را نمی‌دهد؛ دامنه، DNS، مسیر شبکه و محدودیت‌های سرویس میزبانی نیز مؤثرند.
