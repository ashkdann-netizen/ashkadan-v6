# اشکادان | Signature V6 Secure

نسخه پنجم، بازطراحی بصری لوکس با تم مشکی و طلایی شامپاینی است که روی پایه فنی سخت‌سازی‌شده V4 ساخته شده است. ساختار، فرم درخواست، مدیریت پروژه‌ها، پنل ویرایش و امکانات قبلی حفظ شده‌اند؛ ظاهر عمومی سایت بازپرداخت شده است.

## پیش‌نمایش محلی

```bash
npm install
npm run dev
```

سپس آدرس محلی نمایش‌داده‌شده توسط Wrangler را باز کنید.

## کنترل کیفیت

```bash
npm run check
npm test
```

گزارش جزئی در `QA-REPORT-FA.md` قرار دارد.

## تنظیمات لازم پیش از انتشار

این بسته به حساب Cloudflare متصل یا Deploy نشده است. پیش از انتشار:

1. نام پروژه Pages واقعی را در `wrangler.toml` جایگزین کنید.
2. KV namespace واقعی بسازید و شناسه آن را در `wrangler.toml` قرار دهید.
3. R2 bucket بسازید و binding `ASHKADAN_MEDIA` را فعال کنید.
4. Secrets با نام‌های `ADMIN_USER`, `ADMIN_PASSWORD`, `SESSION_SECRET` را در پروژه Pages تنظیم کنید. نام کاربری پیش‌فرض `admin` است؛ رمز باید حداقل ۱۶ کاراکتر و `SESSION_SECRET` حداقل ۳۲ کاراکتر تصادفی باشد.
5. دامنه واقعی را در `public/site-config.js` و فایل‌های sitemap/robots ثبت کنید.
6. در داشبورد Cloudflare Rate Limiting برای `/api/admin/login` و `/api/inquiries` تنظیم کنید. شمارنده KV داخل برنامه best-effort است و جایگزین Rate Limiting اتمیک نیست.
7. در Preview/Production فرم، رسانه‌ها، CSP و رفتار موبایل را آزمایش کنید.

## دستیار پرسش‌های متداول

سؤالات متداول به‌صورت فهرست جداگانه در صفحه عمومی نمایش داده نمی‌شوند. دستیار اشکادان از پرسش‌ها و پاسخ‌های آماده‌ای که در تب «سؤالات متداول» پنل مدیریت ویرایش می‌شوند استفاده می‌کند. اگر پرسش با پاسخ‌های ثبت‌شده تطبیق نداشته باشد، بازدیدکننده به تماس تلفنی یا واتساپ مدیریت هدایت می‌شود. این دستیار مبتنی بر پاسخ‌های ازپیش‌تعریف‌شده است و ادعای هوش مصنوعی آزاد ندارد.

## ورود به پنل مدیریت از داخل سایت

- سایت را باز کنید و در پایین صفحه روی «مدیریت سایت» بزنید.
- نام کاربری پیش‌فرض `admin` است؛ در صورت تنظیم `ADMIN_USER` در Cloudflare همان مقدار استفاده می‌شود.
- رمز را فقط در Cloudflare Pages > Settings > Variables and Secrets به‌صورت Secret با نام `ADMIN_PASSWORD` ثبت کنید؛ رمز را داخل فایل‌ها یا چت قرار ندهید.
- نشست ورود با کوکی امن و HttpOnly تا ۸ ساعت اعتبار دارد. پس از ورود، با بازکردن دوباره پنل تا پایان اعتبار نشست، نیاز به ورود مجدد نیست.
- تغییرات پس از ورود در KV ذخیره می‌شوند و برای همه بازدیدکنندگان قابل مشاهده‌اند. برای بارگذاری تصویر، R2 نیز باید متصل باشد.

## تصاویر و محتوا

تصاویر فعلی برای نمایش سبک بصری هستند و نمونه‌کار واقعی شرکت محسوب نمی‌شوند. تصاویر واقعی، اطلاعات تماس و لینک شبکه‌های اجتماعی باید از پنل مدیریت وارد شوند. تصاویر بیرونی به اینترنت و سرویس میزبان وابسته‌اند؛ برای پایداری بیشتر، نسخه نهایی تصاویر را در R2 بارگذاری کنید.

## یادداشت مهم

هیچ وب‌سایتی را نمی‌توان بدون آزمون روی دامنه، دستگاه‌ها، شبکه‌ها و سرویس‌های واقعی «بدون هیچ ایرادی» تضمین کرد. این بسته تست‌های محلی را گذرانده، اما انتشار واقعی و تست نهایی Cloudflare هنوز انجام نشده است.
